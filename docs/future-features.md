# Future Features & Ideas

A running list of potential enhancements and ideas for the personal site.

## High Priority

- [ ] **Blog Section**
  - Set up a blog index page
  - Create blog post template
  - Add RSS feed
  - Consider static site generator (11ty, Hugo) or keep it simple with markdown

- [ ] **Photography Portfolio**
  - Create a dedicated gallery page
  - Image lightbox/viewer
  - Categories or collections
  - Instagram-style grid layout

- [ ] **Contact Form**
  - Add functional contact form (using Netlify Forms or Formspree)
  - Email notifications
  - Thank you page/message

## Medium Priority

- [ ] **Project Detail Pages**
  - Individual pages for each project
  - More photos and detail about the process
  - Lessons learned sections

- [ ] **About Page Expansion**
  - More detailed personal story
  - Timeline of experiences
  - Photo gallery
  - Favorite music/books/bourbon list

- [ ] **Woodworking Showcase**
  - Dedicated section for woodworking projects
  - Before/after photos
  - Build process documentation

- [ ] **Dark/Light Mode Toggle**
  - User preference for color scheme
  - Save preference in localStorage

## Visual Enhancements

- [ ] **More Interactive Elements**
  - Parallax scrolling effects
  - Mouse-trail particles that react to movement
  - Animated section dividers
  - Rotating 3D elements (inspired by logartis.info)

- [ ] **Enhanced Animations**
  - Stagger animations for project cards
  - More sophisticated text reveals
  - Loading animation/splash screen
  - Smooth page transitions

- [ ] **Custom Graphics**
  - Personal logo/mark
  - Custom icons
  - Illustrated elements
  - SVG animations

## Technical Improvements

- [ ] **Performance Optimization**
  - Lazy loading for images
  - Minimize particle count on mobile
  - Code splitting if site grows
  - Image optimization workflow

- [ ] **SEO Enhancements**
  - Meta tags for social sharing
  - Proper heading hierarchy
  - Alt text for all images
  - Sitemap.xml
  - robots.txt

- [ ] **Accessibility**
  - Keyboard navigation improvements
  - Screen reader optimization
  - Skip links
  - Focus indicators
  - ARIA labels where needed

- [ ] **Analytics**
  - Privacy-focused analytics (Plausible or Fathom)
  - Track popular content
  - Understand visitor behavior

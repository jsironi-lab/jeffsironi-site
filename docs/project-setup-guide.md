# Jeff Sironi Personal Site - Project Setup

## Folder Structure

Here's the recommended folder structure for your personal site project:

```
jeffsironi-site/
├── index.html              # Your main landing page
├── README.md               # Project documentation
├── assets/
│   ├── css/               # Future: separate stylesheets
│   ├── js/                # Future: separate JavaScript files
│   ├── images/            # Your photos, project images, etc.
│   └── fonts/             # Any custom fonts
├── blog/                  # Future: blog posts
├── projects/              # Future: project showcases
└── docs/
    ├── deployment.md      # Deployment instructions
    └── future-features.md # Ideas and roadmap
```

## Files to Create

1. **index.html** - Your main landing page (already created!)
2. **README.md** - Project overview and quick start guide
3. **docs/deployment.md** - Instructions for deploying to your domain
4. **docs/future-features.md** - Running list of ideas and enhancements

## Next Steps

1. Copy all files from this setup into your `jeffsironi-site` folder
2. Update contact links in index.html with your actual email/social media
3. Add your domain name to the deployment docs
4. Start collecting ideas in future-features.md

## Deployment Options

When you're ready to go live, you have several options:
- **Netlify** - Free, drag & drop, custom domain support
- **Vercel** - Similar to Netlify, great for static sites
- **GitHub Pages** - Free hosting if you use GitHub
- **Traditional hosting** - FTP upload to your domain's hosting

## Development Tips

- Open index.html directly in your browser to preview
- Use browser dev tools (F12) to experiment with styles
- Keep backup copies as you make major changes
- Consider using Git for version control once you're comfortable
